1. Скачайте ZIP своей ОС из downloads/.
2. Prism Launcher → Добавить экземпляр → Импорт → выбрать ZIP.
3. Войдите в свой Minecraft Java аккаунт и нажмите Запустить.

В профиле уже указаны Java 21, 6 ГБ памяти, сервер eu-27.enviromc.host:25772.
Первый запуск скачивает 88 модов, последующие сверяют и восстанавливают файлы.
При ошибке обновления игра не запускается; резервные копии: minecraft/.fallens/backups/.
Миры и настройки игрока сохраняются. Старый профиль 26.3 оставьте отдельно.
Сервер проверяет свой пакет до запуска Minecraft, не во время игры.

Windows entrypoint проверен без Prism GUI. macOS shell проверен на Windows через Git sh;
настоящий Mac и игровой вход/рендер/Aeronautics требуют проверки игроком.
