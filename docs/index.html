Вариант macOS подготовлен; первый запуск на настоящем Mac ещё ожидает проверки.

Первый запуск — три шага

  1. Установи Prism Launcher и добавь свой аккаунт Microsoft с купленной Minecraft Java Edition.
  2. Скачай ZIP кнопкой выше. В Prism выбери «Добавить сборку → Импорт из ZIP» и укажи скачанный файл. Распаковывать его вручную не нужно.
  3. Нажми «Запустить» в обычном онлайн-режиме. Для этой версии нужна Java 21. Дождись загрузки Java, игры и модов; если Prism предложит скачать Java, разреши. Адрес сервера уже настроен для автоматического входа.

В следующий раз: просто открой Prism и запусти Fallen's Dream 1.21.1. Повторно импортировать ZIP при каждом обновлении не нужно. Обновления проверяются перед игрой по каналу актуальной сборки. Если сервер обновлений недоступен, запускается уже установленная проверенная версия, а в консоли Prism появляется предупреждение. Так обновлятор работает начиная с 0.2.9n: уже установленному профилю для перехода хватит одного обычного запуска игры с интернетом.

Шейдеры и удобства

Сборка автоматически получает пять вариантов шейдеров: Complementary Unbound, Complementary Reimagined, Photon, BSL и Bliss. При первой установке выбран Unbound на умеренном качестве. В настройках графики открой меню шейдеров: там можно переключить вариант или выключить эффекты. Одновременно работает один набор.

Настройки выбранного шейдера сохраняются при обновлениях. В сборку также входят клиентские оптимизации, удобное управление инвентарём и просмотр рецептов JEI — отдельно скачивать моды не нужно.

Шейдеры: Complementary Shaders — EminGTR, Photon, BSL, Bliss.

Своя музыка

В обновлении 0.2.7n появился Music Disc Maker: создавай пластинки со своей музыкой, слушай их дома, через динамики или в бумбоксе. Мод уже входит в автообновление.

Найди рецепты станка и пустой пластинки в JEI. Открой станок, положи пустую пластинку, вставь ссылку на трек или выбери аудиофайл и подтверди название. Готовую пластинку можно вставить в обычный проигрыватель.

Доступность музыки по ссылкам зависит от источника и региона. Если сервис отклоняет ссылку, используй импорт аудиофайла. Для музыки открой настройки «Музыка и звуки → Музыкальные блоки»; голосовой чат отдельно настраивать не нужно.

Если уже есть старая сборка

Переход с 26.3 / Fabric: скачай ZIP кнопкой выше и импортируй его в Prism как новую отдельную сборку 1.21.1. Старый профиль и его миры сохрани. Автообновление старой ветки не меняет версию Minecraft и загрузчик.

Уже установлен профиль 1.21.1 / NeoForge: запускай его как обычно — обновлятор сам получает новые моды. Скачивать их вручную или заново импортировать ZIP для каждого релиза не нужно.

Если Prism пишет «The process failed to start» или обновление остановилось, сохрани начало консоли со строками Fallen’s Dream / packwiz и передай владельцу. Не добавляй случайные версии модов вручную.

Если Safari скачал папку вместо ZIP

Safari может автоматически распаковать архив. Отключи Safari → Настройки → Основные → «Открывать безопасные файлы после загрузки» и скачай ZIP заново. В Prism выбери исходный ZIP для macOS. Настройка Safari.

Если не подключается

Для ручного входа: «Сетевая игра → Добавить сервер», адрес eu-27.enviromc.host:25772.

Вход разрешён только приглашённым игрокам. Если игра пишет, что тебя нет в списке доступа, сообщи владельцу свой точный игровой ник Minecraft Java.
