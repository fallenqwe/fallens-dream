Первый запуск — три шага

  1. Установи Prism Launcher и добавь свой аккаунт Microsoft с купленной Minecraft Java Edition.
  2. Скачай ZIP кнопкой выше. В Prism выбери «Добавить сборку → Импорт из ZIP» и укажи скачанный файл. Распаковывать его вручную не нужно.
  3. Нажми «Запустить». Дождись загрузки Java, игры и модов; если Prism предложит скачать Java, разреши. Адрес сервера уже настроен для автоматического входа.

В следующий раз: просто открой Prism и запусти Fallen's Dream. Повторно импортировать ZIP не нужно. Обновления проверяются перед игрой и соответствуют версии сервера.

Если не подключается

Для ручного входа: «Сетевая игра → Добавить сервер», адрес eu-27.enviromc.host:25772.

Вход разрешён только приглашённым игрокам. Если игра пишет, что тебя нет в списке доступа, сообщи владельцу свой точный игровой ник Minecraft Java.
