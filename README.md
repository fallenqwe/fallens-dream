# Fallen's Dream

Уютная сборка Minecraft с Create, декором, атмосферными сезонами и шейдерами.
Текущий выпуск: **0.1.1b** · Minecraft **26.3** · Fabric **0.19.5** · Java **25**.

## Установить на Windows

1. Установить [Prism Launcher](https://prismlauncher.org/download/) и добавить свой аккаунт Minecraft Java.
2. [Скачать Fallen's Dream для Prism](https://github.com/fallenqwe/fallens-dream/releases/download/v0.1.1b/Fallens-Dream-Prism.zip).
3. В Prism: **Добавить сборку → Импорт из ZIP** → выбрать скачанный ZIP.
4. Нажать **Запустить**. При первом запуске установщик скачает файлы сборки; Prism установит компоненты игры. При необходимости разрешить Prism подобрать Java 25.

Стартовый ZIP предназначен для Windows и использует штатный Windows PowerShell. Предстартовая команда проверяет Java 25 в установках Prism, даже если переменная `INST_JAVA` пуста.

После установки достаточно нажимать **Запустить**: перед игрой автоматически проверяется канал сборки и применяется опубликованное обновление. Повторно импортировать ZIP для каждого обновления не нужно.

Интернет нужен для проверки обновлений. Если проверка или установка не удалась, запуск останавливается с сообщением в консоли Prism. Незавершённое обновление автоматически откатывается к сохранённым файлам.

По умолчанию игре выделено 4 ГБ памяти. На компьютере с 16 ГБ RAM и более можно выделить 6 ГБ в настройках сборки Prism. Шейдеры можно выключить в настройках Iris.

## Что обновляется

Моды и конфигурация игровых правил приходят из проверенных выпусков. Версии модов закреплены: установщик не выбирает самостоятельно самые новые версии с сайтов.

Миры, серверы, аккаунты, карта и скриншоты не входят в поставку. Существующие графические настройки, клавиши и личные настройки интерфейса сохраняются. Настройки сезонов и сборочных datapack могут обновляться вместе со сборкой.

Перед сменой версии создаётся резервная копия модов, конфигурации и компонентов сборки в `minecraft/.fallens/backups/`. Миры в эту копию не входят: копии миров нужно хранить отдельно. Обновления не должны записывать файлы в `saves/`.
