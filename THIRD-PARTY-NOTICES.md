# Авторы и лицензии

Fallen's Dream — неофициальная сборка Minecraft. Minecraft принадлежит Mojang/Microsoft; файлы игры и аккаунты не распространяются в этом репозитории.

Список закреплённых файлов и оригинальных URL находится в `release-manifest.json`. Права на сторонние моды, текстуры, музыку и shaderpack принадлежат их авторам. Исходные license notices сохраняются внутри JAR.

- [Prism Launcher](https://prismlauncher.org/) — внешний лаунчер, не входит в пакет.
- [packwiz-installer 0.5.14](https://github.com/packwiz/packwiz-installer/releases/tag/v0.5.14), copyright comp500 — MIT; notice в `licenses/packwiz-installer.txt`. Установщик закреплён по SHA256.
- [Create Fly](https://github.com/ZurrTum/Create-Fly/tree/e796c962709fb56eccb3c15ec6a04e8f8dcfa376) — порт Create от ZurrTum, базовый релиз 26.2-6.0.9-2. Отдельные Create, Fabric, Flywheel, NeoForge, Ponder и корневой license notices сохранены в исходном JAR и приложены в `licenses/`. CC0 корневого проекта не заменяет лицензии включённых компонентов. Ассеты Create под All Rights Reserved не переопубликованы: установщик получает официальный JAR от автора и применяет инструкции локального преобразования. [Актуальные исходники port.4 с конфигурацией сборки](https://github.com/fallenqwe/fallens-dream/releases/download/v0.1.2b/Create-26.3-port.4-source.zip) доступны вместе с выпуском; защищённые ассеты для самостоятельной сборки восстанавливаются из официального файла автора. MIT/LGPL/Apache-covered части сохраняют соответствующие условия.
- [Macaw's Windows](https://modrinth.com/mod/macaws-windows) — авторские ассеты/переводы не перенесены на наш хостинг. Исправленные значения русской локализации вычисляются локально из официального файла, а авторские новые строки сохраняют собственное происхождение.
- CozyCases, CozyCatalog, CozySpawn, CozyTagGuard, cozy-act-russian и cozy-mdm-russian — локальные дополнения Fallen's Dream. Наш код и самостоятельно созданные ассеты — MIT. Восстановленные строки сторонней локализации не перелицензируются. Отдельный notice CozySpawn приложен в `licenses/CozySpawn.txt`.
- Complementary Reimagined и остальные сторонние файлы загружаются с оригинальных URL, закреплённых в манифестах; собственные условия авторов сохраняются.

Наши сценарии публикации и обёртка установщика распространяются по MIT (`LICENSE`). Это не лицензирует заново сторонние файлы.

Официальный FAQ разрешает модпаки с указанием автора: https://modrepo.de/minecraft/voicechat/faq. JAR не перезаливается на наш GitHub: клиент получает его по закреплённому URL автора с проверкой SHA512.
