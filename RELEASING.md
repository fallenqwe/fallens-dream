# Выпуски и обновления

## Версии

- `0.1b` — первый beta-выпуск.
- `0.1.1b`, `0.1.2b` — исправления и небольшие настройки без смены направления сборки.
- `0.2b`, `0.3b` — заметный новый контент или изменение правил.
- `1.0.0` — первый стабильный выпуск; далее `1.0.1` для исправлений, `1.1.0` для совместимого контента, `2.0.0` для крупных несовместимых изменений.

Патчноуты описывают изменения для игрока, исправления, проверки и известные ограничения. Смена версии Minecraft/загрузчика или риск для существующего мира указываются явно; такие изменения не выпускаются как незаметный патч.

## Устройство канала

`docs/channel.properties` указывает на неизменяемый каталог `docs/releases/ВЕРСИЯ/pack.toml` и его SHA256. `pack.toml` закрепляет SHA256 индекса; индекс закрепляет SHA256 метаданных; каждый скачиваемый файл закреплён SHA512. Установщик packwiz закреплён на версии 0.5.14.

GitHub Pages хранит манифесты и конфигурацию. GitHub Releases хранит наш установочный ZIP, дополнения и патч. Большинство модов и shaderpack скачиваются напрямую с CDN Modrinth. Оригинальный Create скачивается у автора, а затем адаптируется локально; полный переупакованный Create JAR здесь не распространяется. Восстановление повреждённых строк Macaw's Windows также выполняется локально из исходного JAR.

## Порядок публикации

1. Собрать отдельный кандидат; сохранить исходный состав и возможность отката.
2. Сравнить список модов, проверить совместимость и права на новые файлы, исключить пользовательские данные.
3. Добавить новый каталог `docs/releases/ВЕРСИЯ` и новый выпуск с неизменяемыми assets. Старые каталоги и assets сохранять для отката.
4. Проверить установщик на чистой папке: установка, повторный запуск, переход версии, сохранение настроек/миров и ошибка загрузки с откатом.
5. Опубликовать выпуск и файлы Pages. Сначала проверить их доступность и контрольные суммы; затем переключить `channel.properties` на новый выпуск.
6. Выполнить проверку публичного канала и сообщить ссылку/патчноуты. Новые версии выпускаются после фактического изменения сборки, не по расписанию.

Публикация выполняется владельцем репозитория или Codex по поручению владельца. Секреты и GitHub tokens не нужны игрокам и не должны попадать в ZIP или репозиторий. Изменение сборки на локальном диске само по себе не публикует обновление.

## Локальные проверки

Исходник обёртки установщика находится в `tools/java/FallensUpdater.java`. Он не содержит Minecraft-клиент и не запускает его. Для сборки нужен JDK 25; готовый установщик требует только Java 25, предоставленную Prism.
