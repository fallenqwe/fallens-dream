# Установка, перенос и откат

## Существующая сборка

Публичный ZIP создаёт отдельный профиль **Fallen's Dream**. Он не перезаписывает прежний профиль Cozy Home Create. Для переноса сохранения закройте игру и скопируйте нужную папку мира из старого `minecraft/saves` в `minecraft/saves` новой сборки. Сначала сделайте отдельную копию мира.

Не копируйте целиком старые `mods`, `config`, `packwiz.json` и `.fallens`: они управляются установщиком. Настройки управления и графики можно перенести файлом `options.txt` при закрытой игре; последующие обновления его сохраняют.

## Ошибка загрузки обновления

Откройте консоль Prism. При сетевой ошибке повторите запуск после восстановления соединения. Если ошибка возникла после начала установки, установщик восстанавливает предыдущее состояние файлов сборки; игра в этом запуске не стартует. Если откат тоже завершился ошибкой, не удаляйте `.fallens/backups` и передайте журнал ошибки для разбора.

## Ручной откат файлов сборки

Закройте игру. В папке `minecraft` сборки выполните с Java 25:

```text
java -jar .fallens/launcher.jar . --rollback .fallens/backups/ИМЯ_КОПИИ
```

Затем отключите пользовательскую команду перед запуском в Prism, чтобы канал не предложил то же обновление снова. Для исправленного выпуска включите команду обратно. Откат файлов сборки не меняет мир и не отменяет изменения, сделанные в мире при игре с новой версией. Для такого возврата нужна отдельная копия мира.

Если после прерванного обновления обнаружены новые файлы, которых не было в резервной копии, откат перемещает их в `.fallens/recovery-files/`, чтобы они не загружались игрой и оставались доступными для ручного восстановления. Проверяйте этот каталог, если самостоятельно добавляли моды или конфиги после сбоя.

## Что сохраняется

Установщик не читает и не меняет аккаунты лаунчера. Каталоги `saves`, `screenshots`, карты Xaero и пользовательский `servers.dat` не являются файлами канала. Личные графические настройки и настройки интерфейса входят в поставку как начальные значения с флагом сохранения уже существующих файлов.
