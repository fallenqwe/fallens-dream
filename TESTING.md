# Проверка выпуска 0.1b

Установщик и содержимое пакета проверены без запуска Minecraft и без управления GUI.

- 169 проверок на полной сборке и настоящем packwiz-installer: чистая установка 60 модов, все закреплённые хеши, повторный запуск, восстановление удалённого мода, обновление с заменой имени JAR, сохранение настроек и автоматический откат при повреждённой загрузке.
- 51 отдельная проверка обёртки: применение патча, ограничения путей, повреждённые архивы, восстановление и сохранение новых пользовательских файлов.
- 12 дополнительных проверок с настоящим packwiz: сетевые ошибки, недостающий мод, повреждённый Create, ошибочный хеш канала и старый JAR с атрибутом «только чтение».
- Независимое ревью восстановило 16615 файлов Create из официального оригинала и патча: содержимое совпало с port.3. Каталог также совпал с проверенным JAR по каждому payload entry.
- Проверены исключение личных данных, переносимость стартового ZIP, сохранение лицензий и соответствие опубликованных исходников фактическому port.3.

В этих проверках мир заменялся отдельным контрольным файлом, а Minecraft не запускался. Они подтверждают работу доставки и отката файлов, но не рендер, FPS, качество игрового интерфейса, длительную стабильность или работоспособность на другом ОС. Импорт ZIP и выполнение пользовательской команды именно из GUI Prism остаются клиентской проверкой.

Машинные итоги: `RELEASE-EVIDENCE.json`; контрольные суммы загружаемых файлов — в assets выпуска.

## 0.1.1b

Пользовательский запуск 0.1b обнаружил неразрешённый исполняемый файл Java в предстартовой команде. Предыдущие прямые CLI-тесты Java не проверяли этот шаг лаунчера. Новый скрипт исполнен штатным Windows PowerShell 5.1 при пустом и неверном INST_JAVA, без Java в PATH; все три сценария запуска установщика прошли. Полный GUI Prism и игра автоматически не запускались.
