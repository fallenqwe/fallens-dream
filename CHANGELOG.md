# Патчноуты Fallen's Dream

## 0.1.1b — 19 октября 2026

- Исправлена предстартовая команда Windows: пустой или неверный путь `INST_JAVA` больше не приводит к ошибке запуска процесса до загрузки модов.
- Добавлена проверка Java 25 среди установок Prism. Команда не зависит от наличия Java в системном `PATH` и не меняет глобальные настройки Java.
- Состав модов, Minecraft, Fabric, миры и игровые правила не менялись.

Если ZIP 0.1b уже импортирован и предстартовая команда не запускается, это исправление нужно применить до первого успешного подключения к каналу: импортируйте новый ZIP либо замените команду/скрипт в закрытом профиле. Сам сломанный предстартовый шаг не может загрузить собственное исправление.

Проверено в Windows PowerShell 5.1: пустой, неверный и корректный `INST_JAVA`, Java отсутствует в `PATH`; установщик завершается успешно. Импорт и запуск игры через GUI Prism по-прежнему требуют клиентской проверки.

## 0.1b — 19 октября 2026

Первый распространяемый beta-выпуск.

- Сборка получила имя **Fallen's Dream**.
- Установка через Prism и автоматическая проверка обновлений при запуске.
- Резервная копия файлов сборки перед обновлением и автоматический откат при ошибке установки.
- Create 6.0.9 с адаптацией для Minecraft 26.3/Fabric. Включены исправления загрузки шейдеров и вылета при постановке механической пилы.
- Атмосферные времена года: изменение природы и погоды без сезонных ограничений урожая.
- Iris, Sodium и Complementary Reimagined с профилем MEDIUM.
- Поиск по русским названиям в меню F10, категории и фильтры материала/внешнего вида. Расширена русская локализация.
- Сохранены декор, фермерство, выбор начального биома и локальные дополнения сборки.

### Проверка

Перенос Create прошёл сборку и изолированные проверки ресурсов, рецептов, сетевого кодирования и графических конвейеров без запуска игрового окна. Пользователь проверял игру после исправлений. Полное прохождение и длительная стабильность на разных компьютерах ещё не подтверждены.
