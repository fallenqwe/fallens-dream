# Патчноуты Fallen's Dream

## 0.1.3b —20октября2026

Добавлен Simple Voice Chat2.6.24+26.3 от Max Henkel для разговора рядом с игроками и голосовых групп.

Мод устанавливается автоматически при следующем запуске профиля. После входа на сервер нажмите V: выберите микрофон и назначьте клавишу «нажми и говори». На macOS потребуется разрешение на микрофон для Prism.

Радиус разговора48блоков, шёпота24. Голос использует отдельный UDP-порт из уже включённой квоты хостинга. Игроки без voice-мода могут зайти на сервер.

[Инструкция](https://github.com/fallenqwe/fallens-dream/blob/main/VOICE-CHAT-RU.md) · [Официальный мод](https://modrinth.com/mod/simple-voice-chat/version/OLnMVWXy)

Проверены загрузка мода в серверной сборке и все10точек клиентской интеграции без GUI. Настоящий разговор и разрешение микрофона остаются пользовательской проверкой. Остальной состав сборки, включая исправление Ponder, сохранён.

## 0.1.2b — 20 октября 2026

Исправлены пустые 3D-сцены Create Ponder («Размышление», W).

Учебные схемы старого формата преобразуются штатным Minecraft DataFixer перед загрузкой. Исправление действует независимо от шейдеров.

Проверено: сборка JAR; настоящий клиентский загрузчик Ponder без запуска игры —187/187 схем непустые; обновлятор воспроизводит все16615 JAR entries. Картинка в игре ещё требует проверки игроком. В старой upstream-схеме furnace_engine остаётся один отсутствующий блок; это отдельное устаревшее содержимое.

Обновление клиентское. Сервер и миры не изменяются. Существующие Windows/macOS стартеры получают его при следующем запуске. Для отката сохраняется предыдущий канал0.1.1b и локальная резервная копия обновлятора.

## 0.1.1b — 19 октября 2026

- Исправлена предстартовая команда Windows: пустой или неверный путь `INST_JAVA` больше не приводит к ошибке запуска процесса до загрузки модов.
- Добавлена проверка Java 25 среди установок Prism. Команда не зависит от наличия Java в системном `PATH` и не меняет глобальные настройки Java.
- Состав модов, Minecraft, Fabric, миры и игровые правила не менялись.

Если ZIP 0.1b уже импортирован и предстартовая команда не запускается, это исправление нужно применить до первого успешного подключения к каналу: импортируйте новый ZIP либо замените команду/скрипт в закрытом профиле. Сам сломанный предстартовый шаг не может загрузить собственное исправление.

Проверено в Windows PowerShell 5.1: пустой, неверный и корректный `INST_JAVA`, Java отсутствует в `PATH`; установщик завершается успешно. Импорт и запуск игры через GUI Prism по-прежнему требуют клиентской проверки.
